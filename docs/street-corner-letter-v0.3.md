# 街角的秘密：外地來信 v0.3

## 本輪目的

先讓玩家喜歡這個冬夜街角，願意讀小葵的信，再用生活語言試著回信。情境行為測試可驗證介面狀態與匯出完整；不代表真人學習效果、需求、採用或訂單已被驗證。

## Paul 在本輪的決定

- 主要下一站改為《一盞燈的約定》，貿易街改為次要；語言參數同步。
- 問法要輕鬆，但故事有趣且不流於淺薄。第一版較複雜的實務問法沒有被 Paul 接受為其經驗結論。
- 小葵英文名已由 Paul 定為 Sunny。
- 小葵會與 Grokbot 主導的《一盞燈的約定》連動，是同一個角色。跨作品設定另附桌面交接。

## 實作範圍

- 清掉可見的計數與步驟編號，進度改為圓點和不帶數字的文字。保留文法上的「一封」及正式作品名；不是對所有中文字的一、二等做無差別刪除。
- 按本輪 Owner 授權，揭露改用「示意玩具，不是店家分析」及虛構情境說明；首頁只同步街角卡的 boundary。SITE_RULES 舊版的成效未驗證標示由此次明確授權取代。
- 結果預設保留觀察、下一個問題與小動作、外地信件；其它放入原生 details，預設收合。
- 街角筆記改成原生 dialog；關閉回到觸發光點，避免以整頁自動捲動才能找到筆記。
- 小葵的信以 HTML 呈現，七個不同按鈕對應模糊說法。「固定／送一些」分成相鄰按鈕，避免巢狀互動元素。
- 玩家可立刻選擇回信，不要求先讀滿筆記。回信保留兩個空格，使用短問句、可重排和替換；深入筆記仍可自由探索。這是依 Paul 後續簡化指示調整原企劃的讀取門檻與空格數。
- 筆記標示「可能意味 · 猜測」「可以回問 · 問法示例」，不聲稱是 Paul 確認的實務或經查證的業界準則。
- 回信沒有對方回答，故所有主題都仍待確認：已選的是「回信寫好了，還要等小葵回答」；未選的是「還留在筆記裡，還沒確認」。不與燈的已講好標籤混為一談。
- 每個回問有固定的小故事收尾，無隨機預測，未寄出回信、未產生真實交易。
- 語言切換保留問題與順序，重玩或換時段清除上一段回信；已保存回信與編輯中的草稿分開，取消編輯保留上一版結果與匯出。沒有完成第二幕時不匯出空區塊。
- 匯出先計算所有換行與區塊高度；長回信增加 PNG 高度，保留既有檔名和寬度，不以縮小字級或截斷文字塞入原尺寸。

## 與原交接的差異

- 「先問就先變清楚」改成問題仍需等答覆。
- 原本較重的樣品、停送及多段付款追問改成自然短句。詳細未知留在可選筆記。
- 主連結依 Paul 的明確答覆改為燈。
- 信件稱謂使用「您好」，不使用網站規則禁止的老闆稱呼。
- 不加分享網址，不修改其它作品、不做後續可選階段或新美術。
