# 街角的秘密：情境對照與觀察路徑 v0.2

## 目的

讓訪客在平日傍晚與週末傍晚各看一次同一個虛構街角，練習分清「兩次情境都看見什麼」與「仍需要更多觀察才能知道什麼」。這輪深化不增加新追查路線、分數、徽章或複雜劇情。

## Claim under test

在這個短篇虛構案例中，訪客可以指出可見線索、可能解釋與未知，並說出為什麼兩個時段的相同線索仍不足以證明需求穩定。

## 最小改動

- 玩家在平日與週末各點一次「隊伍」後，顯示雙語對照區，列出兩個時段各自看到的線索。
- 對照區說明兩個時段沿用同一幅插畫與相同線索；整體虛構情境限制集中在結果頁底部與下載卡。
- 顯示「相同線索／仍未知／下一個可查問題」，下一步建議在相近時段重複記錄等候、取預訂與現買。
- 下載觀察卡包含相同的跨時段對照和限制句。單次探索維持原有流程。
- 結果頁提供一個預設收合的延伸閱讀，沿「等候 → 原因 → 完成交易 → 回訪與供應」說明每一步能看懂什麼、還不能推論什麼；手機版收緊步驟間距，維持原字級。
- HTML 的繁中預設文案與頁面載入後的文案保持一致。
- 證據路徑以「排隊不等於買單，就像詢盤不等於訂單」收尾；中英文同步。一般限制句只在結果頁底部與下載卡各出現一次，保留必要的情境和假設標示。

## 證據與驗收

- 證據類型：互動路徑與文案的情境測試；不是使用者採用或商業成效證據。
- 完成條件：只有在兩個時段都看過隊伍後才顯示比較；繁中與英文意思一致；鍵盤可達；下載卡也包含兩時段、下一個觀察問題和單一限制句；390／1440 的中英收合與展開畫面留存。
- 體驗檢查目標：訪客能說出兩個快照的共同線索，以及仍需重複觀察的原因。未經真人檢查，不宣稱已達成。
- 延伸閱讀目標：訪客能分辨排隊、交易和回訪是不同層次的證據；展開內容不應阻擋原本的短流程。

## 必須保留的限制

三位等候者是插畫中的可見元素。時段切換不代表新照片、真實訪次、客流資料、回訪、需求或擴店結果。只有實際且合規的觀察才可能補上這些未知。

## 停止條件

若雙語對照造成「模擬快照等於實測」的誤讀、增加過多步驟，或下載卡無法清楚呈現限制，就先撤回對照，不增加更多情境或分析功能。
