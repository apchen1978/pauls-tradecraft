# ROOMVERSE 3D：圍巾側面厚度（第四輪）

## 問題

線上看正面、手機都過得去，但從側面看像兩片薄片：布只有前後兩層平面，邊是銳的，沒有厚度。

## 這輪只改側面（正面輪廓、織紋、顏色、尺寸、尾巴長度、流蘇都沒動）

1. **截面改成封閉的圓角環**：前緣 → 右側圓邊 → 後緣 → 左側圓邊。側面看到的是有厚度的布邊，像縫邊，不再是兩張紙。
2. **折頂連成一條布**：鉤子上方的 180° 回折沿同一條中心線連續過去，圓角截面讓回折處看起來是一塊布轉彎，不是兩片各自下垂。
3. **厚度不一致**：中段約 1.0 cm、下擺約 0.78 cm，沿長度再加 ±4% 起伏；內側（後緣）用頂點色調暗到 0.82，內面織紋比較深。

## 頂點預算

- 圓角環的截面點數：`2 × (across+1) + 2`；用 `across=3, along=48` → 每條布 490 頂點，**和原本的兩層平面版一樣**。
- 整座衣帽架仍是 3,959 頂點（上限 4,000），沒有調高上限。
- `clothEdge` 維持 0.26（其他物件 0.18），本輪沒有再放寬。
