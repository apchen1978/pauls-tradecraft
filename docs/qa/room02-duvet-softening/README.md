# Room 02：被子軟化與明度分離（任務卡 01）

## 範圍

只改 `duvetGeo()` 與床品顏色；不動披毯、枕頭、相機、窗簾、燈、其他物件。段數維持 26×30。

## 改了什麼

1. **垂墜波**：垂墜區加低頻重力下垂（振幅約 1.8 cm、波長約 40 cm），從捲邊下方漸入，捲邊處保持貼合。
2. **捲邊半徑 5 cm → 7 cm**：床緣的翻摺更厚，側面不再是薄邊。
3. **轉角斜皺褶**：床尾與側面垂墜交界（`|ex−ez|` 小於約 4 cm 的區帶）加 2–3 道斜向起伏，取代原本一條硬折角；位移放在 X/Z 方向，不降低下擺高度。
4. **下擺不完全直線**：下擺沿邊加 ±1.5 cm 的雙頻起伏。
5. **明度分離**：床單（`sheetMat`）由 `#ece4d4` 改為 `#efe8dd`（亮度約 +4%，略降暖度）；被子加上暖色乘數 `[1.03, 0.995, 0.94]`（相對更暖約 3%）。換色選項（stone／mist／clay）同步套用同一個乘數，不會因為換色把分離拉平。
