# ROOMVERSE 寬幅明信片構圖選稿

這三張是同一間房的取景概念，先供 Paul 選方向；尚未改明信片程式，也沒有更新像素比較測試。每張都是 1200×664 PNG，保留目前明信片的標題、配置標籤與頁尾。三張都保留完整牌匾「Christ is the Head of this House」。

| 選項 | 取景 | 畫面取捨 |
|---|---|---|
| A | 窗邊正面，角度 0°、垂直 FOV 56° | 最接近目前明信片，窗戶與沙發最突出；右牆畫作只露出一部分。 |
| B | 稍向右牆，角度 340°、垂直 FOV 58° | 窗戶、沙發、右牆畫作和房門都進來；牌匾仍清楚，空間感最平衡。 |
| C | 更寬的轉角，角度 20°、垂直 FOV 70° | 收進更多牆面與房間邊界；視角最寬，物件透視感也最強。 |

## FACT

- 三張都由同一個 ROOMVERSE 3D 房間即時畫面取景，再沿用現有明信片頁尾；沒有新增或重畫房間資產。
- 牌匾四角均在畫面內，沒有物件遮住文字。投影座標詳見 `measurements.json`。
- 本輪沒有修改網站程式、正式明信片、明信片像素比較測試或公開頁面。

## INFERENCE

B 最符合「窗邊、沙發、部分右牆都看得到，牌匾仍清楚」的平衡方向。A 保守穩定，C 最寬但較容易讓人感到廣角。
