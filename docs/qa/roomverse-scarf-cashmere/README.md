# ROOMVERSE 3D：紅圍巾改成精品喀什米爾風

## 結論

原本的紅圍巾是一片直的薄板。這次把它做成**真的布**：180×30 cm、厚 1 cm、兩端各 8 cm 流蘇、掛在鉤子上有自然垂墜與微扭轉，兩條尾巴一邊 85 cm、一邊 75 cm，細人字織紋加凹凸貼圖。沒有 logo、沒有字樣。

## 做法（全部程式生成，沒有用混元掃描）

1. **尺寸照真實**：寬 30 cm、厚 1 cm、布長約 162 cm（含兩端 8 cm 流蘇約 178 cm ≈ 180 cm），垂墜 85 / 75 cm。
2. **兩條尾巴分開**：中心線在鉤子附近把兩片布錯開 2 cm，掛上去才看得出是兩層，不是一片。
3. **鉤子處收窄**：布被鉤子夾住，寬度從 55% 往下展開成 100%，避免頂端像一塊方板。
4. **扭轉與皺摺**：整條布沿長度慢慢扭轉（±0.30 rad），加上三層不同頻率的皺摺，垂墜有起伏。
5. **人字織紋 + 凹凸**：256×256 的 canvas 織紋（暖紅 #a83234 為底、明暗斜線交錯），另做一張同圖的 bumpMap，讓布面會吃光。
6. **流蘇**：兩端各一片 8 cm 的透明貼圖面（26 條細線、長度略不齊），雙面材質、alphaTest 0.35。
7. **材質**：roughness 0.96、metalness 0、DoubleSide——布料沒有亮面反光。
