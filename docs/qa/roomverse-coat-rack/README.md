# ROOMVERSE 衣帽架

獨立衣帽架立在房間左前方的角落，進房就能看見，不是選項、也不替換植物。米色大衣和奶油圍巾留在架上。右牆門邊的智能面板和電燈開關、左牆白板、兩面掛畫、木牌「基督是我家之主」都沒有被擋住。植物在左後角，矮椅在左側中段，衣帽架沒有靠上它們。

## 尺寸與位置

高 **1.78 m**，圓底座直徑 **0.42 m**，底面貼地。底座靠近左牆、電視牆前面那一截空位，整組大約在 x -2.41 到 -1.95、z 1.65 到 2.18。離左牆掛畫、電視櫃和層板都還有空隙。跟門、面板、開關、出風口、沙發、植物、矮椅、落地燈、茶几、木牌、白板、電視櫃沒有相交。

胡桃木立柱略有光澤，黃銅鉤是柔和的金屬高光，大理石底座有一層淡反光，大衣和圍巾是啞光毛料。反射只取房間當下的樣子。地板有一圈接觸暗影，左牆靠近電視的那一段有一道淡影。六種氣氛沿用房間原有的燈，不另加光源。

檔案 `coat-rack.glb` 約 785 KB。進房後的第一批模型仍是原來的 9 個；衣帽架等房間可以轉動之後才載入，載入後就留在場景裡。
