# ROOMVERSE 手機操作列

390px 寬時，三個動作改到 3D 房間正上方的一列：看短片、隨機搭一間、存成明信片。點下去不用再往上捲。電腦寬度仍把這三個按鈕留在右側面板裡。

- `390-zh.png`、`390-en.png`：進入房間後的第一屏。
- `390-zh-after-random.png`：點「隨機搭一間」之後，房間仍在畫面裡。
- `1440-zh.png`：電腦版按鈕位置沒有改。

中文手機的 3D 畫面高度沒有改，牆上「Christ is the Head of this House」牌子的取景與燈光維持原樣。英文手機把房間高度少掉這一列的 60px，讓「回到窗邊／看電視牆」仍在第一屏。

「隨機搭一間」仍不改感覺。牆、地毯、窗簾、掛畫各自從扣掉目前選項的清單裡抽；抽完若整組和點下去之前相同，就用同一種抽法再抽一次。
