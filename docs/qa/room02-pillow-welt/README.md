# Room 02：枕頭／抱枕滾邊與受壓（任務卡 02＋03 件 1）

## 範圍

只改 `pillowGeo()`、枕頭／抱枕參數與它們的接觸陰影；不動被子、披毯、床架、相機、窗簾、燈、衣櫃。Codex 的圖轉 3D 枕頭 GLB 未使用。

## 第一版（PR #475 初版，CC 審查後暫不合併）

- 邊界滾邊、封閉邊條、白枕 19 cm／抱枕 16 cm、角度不同、受壓凹陷。
- **問題**：抱枕抬到 `BED.top + .235` 後在近拍裡懸在白枕上方，下緣是一條硬折線。

## 這一版修法（件 1）

1. **抱枕真的壓在白枕上**：`y = BED.top + .265`（比白枕頂面低約 2 cm，兩者實體重疊）、後傾 `−.42`、`z = north + .215`；下緣陷進白枕的凹處，不再有透光縫。
2. **滾邊 1.8 cm**：`welt .010 → .018`（註解先前寫 1.8 cm、程式只有 1 cm，已對齊）。
3. **底面改平**：`prof = side > 0 ? t : Math.min(1, t * 2.1)`。兩個球面相切時只接觸一個點，才會「看起來浮空」；底部壓平後是面接觸。
4. **凹陷更明顯**：白枕 `dent .026`、抱枕 `dent .018`。
5. **移除抱枕的假接觸陰影**：它會埋進枕頭裡；抱枕本身 `castShadow`，由真實陰影落在枕面上。
