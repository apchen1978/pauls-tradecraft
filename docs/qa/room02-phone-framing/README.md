# Room 02 phone opening framing

Opening look (`center`) on a 390-wide phone: yaw 0 -> -0.06, pitch -0.22 -> -0.20, zoom 0.8 -> 0.76.

- `before-390.png`: production before the change (canvas only).
- `after-390.png`: the same page with the new look values applied in-page (a simulation of the change, not a deployed capture).

Both were taken on the live page at 390 x 844 with the same mood. Yaw beyond about -0.065 pushes the house plaque out of frame (`plaqueInView` false), so -0.06 is the limit.
