Base main: `03edca7` (2026-10-20). Independent branch/worktree. Draft only.

## FACT: implementation

- Right wall at x = 2.6 m, centre z = 1.25 m; frame spans z = 0.725–1.775 m.
  Frame outside size 1.05 × 2.10 m. The nominal 0.90 × 2.05 m opening contains a
  0.886 × 2.038 m leaf, allowing narrow side reveals and an 8 mm bottom clearance.
  Leaf projects 2 cm inside the wall; trim projects 4.5 cm. Lever centre is 1 m high.
- One opaque illustrated light-oak map, 450 × 1024, **35,006 bytes**. Source PNG and
  prompt retained; see [source/prompt receipt](PROMPTS.md). Warm-white frame uses
  the existing skirting material. Brass lever/rosette/hinges are geometry.
- Right skirting stops exactly at the two frame edges. Closed wall remains behind
  the leaf, preventing window-light leakage. The door has no click/open behaviour.
- The map shares the existing `image()` helper and post-entry idle schedule. It
  also loads when entering the TV view or orbiting toward the door. The fallback
  is a complete plain wooden door; a failed map cannot reject room startup.
- No UI text, MOODS light parameters, camera limits/tour route, existing GLBs,
  other works, or existing QA image content changed.
- Actual world bounds show no intersections with sofa, side table, floor lamp,
  coffee table, plant, robot or low chair. See [render diagnostics](visual-checks.json).

## Reproduce images

Run a local Vite server on 4186 (or set `ROOM_QA_URL`), then:

```powershell
node docs/qa/roomverse-door/capture.mjs
python docs/qa/roomverse-door/contact-sheets.py
```

Source PNGs are retained on Desktop, not served by the website. QA screenshots
are only encoded/resized/contact-sheeted; the room artwork is not painted in Python.

## INFERENCE / UNKNOWN

The door's neutral trim and oak grain fit the existing joinery without competing
with the sofa area. This is an illustrated closed-door scene detail, not a
construction drawing. Physical phones/Safari, production networking and visitor
hardware remain untested. The additional local mobile preparation time is measured;
its behaviour on other hardware is unknown.
