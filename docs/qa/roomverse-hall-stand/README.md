# ROOMVERSE 衣帽架

線上那件米色大衣會碎，是因為模型本身的三角形被削得太狠，不是手機少畫了一面。

那個檔是一整個網格、六萬個三角形。大衣那一段最長的邊有 25 公分，柱身那一段最長的邊有 73 公分。薄布和細柱被拉成又長又尖的三角，近看就是破洞和碎片。材質檔本來就開了雙面，所以不是背面被剔掉。檔案裡也沒有記下「簡化 4%」這個數字；量到的就是這種削過的結果。桌面遠看時，米色貼圖會把破洞糊過去；手機靠近看，灰灰的碎片就露出來。

大衣整件拿掉，棒球帽也拿掉。柱子、鉤子用乾淨的圓柱和圓管重做，一條紅圍巾留在鉤上。底座改成約 41 公分寬、3.6 公分厚的深色磨石圓盤，外緣是圓角，柱子插進短短的石領。石面有淡紋和一點粗糙變化，不再是平塗的淺色圓片。地板上有一圈貼著底座的接觸暗影。沿用房間原有的燈，沒有另加光源。白板、門邊面板、出風口、木牌都沒有改。

場景裡量到的尺寸：整組高 1.779 公尺。木柱上端直徑 3.1 公分、下端 3.5 公分。鉤子 6 支，冠在離地 1.650 公尺，每支露出 14.0 公分。紅圍巾長 1.626 公尺、寬 25.0 公分、厚 1.0 公分，掛上之後兩邊各垂下 80.0 公分。底座直徑 41.0 公分，圓盤厚 3.6 公分。立在左前角。植物、矮椅、門、面板、開關都沒有靠上。對照畫面把圍巾下擺和底座放在同一格，那顆圓盤就是旁邊已知的大小。
