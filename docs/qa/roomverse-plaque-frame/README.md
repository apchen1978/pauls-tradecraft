# 手機窗邊視角：木牌整塊入鏡

390 寬的窗邊視角會切掉「基督是我家之主 / Christ is the Head of this House」木牌右側。牌子的位置和大小沒有改。手機窗邊視角的垂直視野改成剛好把木牌右緣收到畫面內（NDC 0.96），電視牆視野維持原本用來包住層架的角度，電腦 1440 仍是 44°。

白板、門把側智慧面板、天花出風口都在場景裡。木牌和這三樣沒有相交，窗邊視角打到木牌中心的第一個面仍是木牌。

截圖是 Chrome、裝置像素比 1、減少動態，家庭感窗邊視角。1440 的前後兩張像素相同。
