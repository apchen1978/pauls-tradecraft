# ROOMVERSE 中央空調與智能面板

畫廊作品〈當牆也有了風景〉的定稿是 `docs/gallery/sources/ai-lab-digital-room-smart-home-wallpaper-v3.png`，公開圖是 `public/gallery/assets/ai-lab-digital-room.webp`。控制板沿用淺色外殼、深色螢幕、23° 與雪花，並加一個小燈圖示。沒有壁掛冷氣。

天花板靠窗的一邊仍是那條內縮的線型出風口。控制板改到入口門的門把側，外緣離門框約 12 公分，中心高度 1.30 公尺。旁邊加了一塊同色的雙切開關板。木牌「基督是我家之主 Christ is the Head of this House」沒有被擋住。掛畫左側的空牆和四個角落都沒有放東西。沒有新增光源。
