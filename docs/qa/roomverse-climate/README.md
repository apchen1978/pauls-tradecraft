# ROOMVERSE 中央空調與智能面板

畫廊作品〈當牆也有了風景〉的定稿是 `docs/gallery/sources/ai-lab-digital-room-smart-home-wallpaper-v3.png`，公開圖是 `public/gallery/assets/ai-lab-digital-room.webp`。牆上的控制板沿用那幅畫的淺色外殼、深色螢幕、23° 與雪花，另外加了一個小燈的圖示。沒有壁掛冷氣。

天花板靠窗的一邊有一條內縮的線型出風口，霧白、中間是一條深灰槽。控制板在後牆，沙發掛畫和木牌之間，中心約 1.32 公尺，面寬約 10.4 公分。木牌「基督是我家之主 Christ is the Head of this House」沒有被擋住。掛畫左側的空牆，以及房間四個角落，都沒有放東西。沒有新增光源；螢幕只用本身的淡光。
