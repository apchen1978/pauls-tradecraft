# Paul's Tradecraft

Source for https://paulstradecraft.com — a portfolio site of small working tools
and case notes on international trade.

Built by Paul Chen, with 15 years in international sales. It is a place to share
methods, not a storefront: how to find buyers, work out margins and close orders,
made into things you can try.

## What you'll find

- **Trade tools and case notes** — working through the path from product to buyer.
- **AI Lab** — notes on working with AI agents, with interactive explainers.
- **ROOMVERSE** — interactive 3D rooms, bilingual (中文 / English).

The site is built in the open with AI as a collaborator.

## Developing

- React + Vite + Tailwind; `npm install && npm run dev` to run locally
- `npm run build` outputs the static site; GitHub Pages deploys from `main`
- Static demo pages live under `prototype/`; `.github/workflows/deploy.yml` lists which ones are published
