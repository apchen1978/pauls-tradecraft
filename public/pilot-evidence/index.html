01 追蹤器結構 Tracker Anatomy

單一 Excel 工作簿：從網站名單（Leads）一路到跟進（Follow-ups）、報價（Quotes）、丈量（Measurements）與每週 KPI（Dashboard）。

Lead 建立→ 24h 首次聯繫→ 資格評估→ 丈量預約→ 報價→ 成交 / 失單

72h 未回覆不判定 lost → 轉 nurture 培育（Pilot #002 慣例）；報價前需（虛擬）丈量（Pilot #001 慣例）。

02 四期模擬 Four Simulation Rounds

每一期都在前一期的資料模型上推進：完整流程 → 低資訊培育 → 報價版本化 → 未知值稽核。

03 23/23 驗證 Verification

以零依賴 Node 腳本（build / simulate / inspect / verify）產出並驗證追蹤器，跨工作表交叉檢查 + 公式錯誤掃描全數通過。

本機重跑（zero-dependency, Node）：

node work/build_curtain_pilot_tracker.mjs
node work/simulate_pilot_001.mjs
node work/simulate_pilot_002.mjs
node work/simulate_pilot_003.mjs
node work/inspect_curtain_tracker.mjs
node work/verify_pilot_002.mjs
node work/verify_pilot_003.mjs

04 證據檔下載 Evidence Files
