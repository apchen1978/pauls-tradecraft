# Room Mode Remote — Chic City Scene

- `room-chic-v1.png`: generated portrait room artwork used as the source for the two responsive WebP assets in `public/prototype/room-mode-remote/assets/`.
- `furniture-robot-v1.png`: existing ROOMVERSE robot illustration, reused as a separate transparent scene overlay.
- `wall-plaque-text-v1.webp`: existing ROOMVERSE plaque artwork, reused unchanged so the approved English wording remains exact.
- Scene art depicts a pink everyday laptop, a small terracotta low chair, and a restrained American-style botanical wallpaper. The displayed laptop is unbranded; it is a visual reference, not a product specification.

The responsive WebP files are technical resizes/encodes of the generated source. The robot is alpha-cropped and optimized to WebP for its canvas overlay. No new package was added.
